# Contributing to proetsy\n\n## Dependency Management\n\nThis is a **monorepo** with multiple workspaces. Proper dependency management is critical to avoid structural debt.\n\n### Core Rule\n\n**Shared tools** → Root `package.json`  \n**Runtime dependencies** → Workspace-specific `package.json`\n\n### Dependency Categories\n\n#### 🔧 Shared Tools (Root Only)\nThese are used across multiple workspaces and should **never be duplicated**:\n\n```json\n{\n  \"devDependencies\": {\n    \"typescript\": \"^5.x\",\n    \"eslint\": \"^8.x\",\n    \"prettier\": \"^3.x\",\n    \"husky\": \"^8.x\",\n    \"lint-staged\": \"^14.x\",\n    \"@typescript-eslint/eslint-plugin\": \"^6.x\",\n    \"@typescript-eslint/parser\": \"^6.x\"\n  }\n}\n```\n\n#### 🚀 Backend Runtime (Backend Workspace Only)\n\n```json\n// backend/package.json\n{\n  \"dependencies\": {\n    \"express\": \"^4.x\",\n    \"cors\": \"^2.x\",\n    \"dotenv\": \"^16.x\"\n  }\n}\n```\n\n#### ⚛️ Frontend Runtime (Frontend Workspace Only)\n\n```json\n// frontend/package.json\n{\n  \"dependencies\": {\n    \"react\": \"^18.x\",\n    \"react-dom\": \"^18.x\"\n  }\n}\n```\n\n### Workspace Structure\n\n```\nproetsy/\n├── package.json                    ← Shared tools, workspace config\n├── backend/\n│   ├── package.json               ← express, dotenv, backend-specific deps\n│   └── src/\n└── frontend/\n    ├── package.json               ← react, react-dom, frontend-specific deps\n    └── src/\n```\n\n### Before Adding Dependencies\n\n1. **Ask:** Where will this package be used?\n   - Used in multiple workspaces? → Add to **root** `devDependencies`\n   - Used only in backend? → Add to **backend** `dependencies`\n   - Used only in frontend? → Add to **frontend** `dependencies`\n\n2. **Check:** Does it already exist?\n   ```bash\n   grep -r \"package-name\" . --include=\"package.json\"\n   ```\n\n3. **Verify:** Run the audit locally\n   ```bash\n   npm run audit:deps\n   ```\n\n### Common Mistakes\n\n❌ **DON'T:**\n```bash\n# In backend workspace\nnpm install typescript          # ← Share via root\nnpm install react               # ← Wrong workspace\nnpm install react react-dom     # ← Duplicate if in root too\n```\n\n✅ **DO:**\n```bash\n# From repo root, add shared tool\nnpm install --save-dev typescript\n\n# From backend workspace, add runtime dep\ncd backend && npm install express cors\n\n# From frontend workspace\ncd frontend && npm install react react-dom\n```\n\n### CI/CD Checks\n\nEvery PR runs:\n- **Duplication Check**: Catches packages appearing in multiple workspaces\n- **Structure Validation**: Ensures shared tools stay in root\n- **Lockfile Integrity**: Prevents version mismatches\n- **Security Audit**: Flags known vulnerabilities\n\nFailing these checks blocks merge.\n\n### Running Audits Locally\n\n```bash\n# Check for duplication\nnode scripts/check-dependency-duplication.js\n\n# Validate structure\nnode scripts/validate-workspace-structure.js\n\n# Both (shorthand)\nnpm run audit:deps\n```\n\n### Questions?\n\nIf you're unsure about where a dependency belongs:\n1. Check the package's documentation for intended usage\n2. Run `npm run audit:deps` to see if there are warnings\n3. Ask in the PR or open an issue\n\n**Goal:** Keep the monorepo clean and dependencies lean. 🎯\n"
